> **VOX FIRE** (also known as **VOXFIRE** and **VOXFIRE.io**) is a fast-paced, free-to-play **3D online multiplayer first-person view (FPV) shooting game** running entirely in your web browser. Built with Three.js, WebGL, and WebRTC, VOX FIRE lets you drop straight into instant multiplayer combat on PC, Mac, Chromebook, Android, and iOS without downloading, installing, or registering.

Play instantly at: **[https://parshvashah2008.github.io/voxfire-io/](https://parshvashah2008.github.io/voxfire-io/)**

## 🎮 Highlights & Game Features

- **🌐 Real-Time Online Multiplayer**: Drop directly into live public matches with players worldwide or create custom private rooms to play with friends.
- **👥 2 Player & 4 Player Private Rooms**: Host 1v1 private duels, 2v2 tactical squad skirmishes, 4-player free-for-all, or up to 8-player custom lobbies with **zero bots**.
- **🔥 Multiple Game Modes**:
  - **Global Players (GTA Online Style)**: Seamless drop-in public matchmaking with live online players worldwide.
  - **4v4 Terrorist vs Anti-Terrorist (T vs AT)**: Tactical squad combat with interactive pre-match team selection.
  - **Team Deathmatch (TDM)**: Classic Red vs Blue faction warfare.
  - **Gun Game**: 20-tier weapon progression where every elimination awards your next firearm.
  - **Free For All (FFA)**: High-speed all-versus-all voxel deathmatch.
  - **Offline / Practice**: Solo training with intelligent AI bots across custom difficulty levels.
- **📱 Precision Mobile Touch Controls**:
  - Full touch-friendly HUD with dual fire buttons (right thumb + left claw trigger).
  - Built-in **intelligent Auto-Fire**: automatically fires when enemies enter your crosshair with direct bullet guidance.
  - Clamped high-contrast laser reticle with reflex red-dot aiming.
- **⚡ High Performance 3D Engine**:
  - Powered by Three.js WebGL with ACES Filmic tone mapping and dynamic shadow lighting.
  - Smooth high-refresh gameplay supporting 60 FPS, 90 FPS, and 120 FPS displays.
  - Instant load times (< 3 seconds) with zero downloads or plugins required.
- **🔫 20+ Weapons Arsenal**:
  - Assault Rifles (AK-47, M4A1, Scar-L, AUG)
  - SMGs (MP5, Vector, P90)
  - Sniper Rifles (AWP, Scout, Barrett .50)
  - Shotguns (Spas-12, Sawed-Off)
  - Sidearms (Desert Eagle, Glock-18, Revolver)
  - Tactical Gear (Frag Grenades, Smoke Grenades, Combat Knife)

## 🕹️ Controls

### Desktop (Keyboard & Mouse)
| Action | Key / Control |
|---|---|
| **Move** | `W`, `A`, `S`, `D` |
| **Look / Aim** | Mouse Movement |
| **Fire** | Left Mouse Button (`LMB`) |
| **Aim Down Sights (ADS)** | Right Mouse Button (`RMB`) |
| **Jump** | `Spacebar` |
| **Crouch / Slide** | `C` or `Shift` |
| **Reload** | `R` |
| **Weapon Swap** | `1`, `2`, `3` or Mouse Scroll Wheel |
| **Throw Grenade** | `G` |
| **Pause / Menu** | `Esc` |

### Mobile & Tablet (Touch)
| Action | Touch Gesture |
|---|---|
| **Move** | Left Virtual Analog Joystick |
| **Look / Aim** | Swipe anywhere on the right half of screen |
| **Primary Fire** | Right Thumb Fire Button |
| **Claw Fire** | Left Upper Claw Button |
| **Auto-Fire** | Toggle button in top-right header (fires automatically when aimed at enemy) |
| **ADS / Scope** | ADS Button on right edge |
| **Jump / Crouch** | Dedicated ergonomic thumb buttons |

## 🚀 How to Play With Friends (2 Player & 4 Player)

1. Open **[VOXFIRE.io](https://parshvashah2008.github.io/voxfire-io/)** in your browser.
2. In the Main Menu, click **Choose Mode** ➔ **Private Room (With Friends)**.
3. Click **Host Room** to generate your unique 6-character room code.
4. Copy the room invite link and send it to your friends on Discord, WhatsApp, or Telegram.
5. Once your friends click the link or enter the code, select your arena and game mode, and jump straight into battle!

## 🛠️ Technology Stack

- **Client Engine**: HTML5, Vanilla JavaScript (ESNext), Three.js (r128+), WebGL
- **Networking**: WebRTC Peer-to-Peer DataChannels, PeerJS signaling
- **Audio**: Web Audio API with spatial 3D positional sound effects
- **Rendering**: ACES Filmic tone mapping, PCF soft shadow maps, frustum culling
- **Hosting**: GitHub Pages with HTTPS, ServiceWorker PWA caching, and Schema.org SEO
